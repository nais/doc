### http.maxContentLength
Maximum content length for HTTP requests to the OpenSearch HTTP API. Default is 100mb.
The value is specified as a Kubernetes resource.Quantity, e.g. "100Mi", "1Gi".
Unitless values are interpreted as bytes.
Minimum value is 1048576 bytes (1Mi), maximum value is 2147483647 bytes (approximately 2047Mi).

### shardIndexingPressure.enforced
Run shard indexing backpressure in shadow mode or enforced mode.
In shadow mode (value set as false), shard indexing backpressure tracks all granular-level metrics, but it
doesn’t actually reject any indexing requests. In enforced mode (value set as true), shard indexing backpressure
rejects any requests to the cluster that might cause a dip in its performance.

Type: `boolean`<br />
Required: `false`<br />
