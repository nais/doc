# Vulnerability insights and management

Nais provides what you need to secure your software supply chain and manage vulnerabilities in your workloads.

The [SBOM and vulnerability detection overview](explanations/sbom-and-vulnerabilities.md) explains how image builds, scanning, Nais API and Console fit together.

Get started by using our [GitHub Actions](how-to/sbom.md) to generate SBOMs and attestations for your workloads.

Once this is in place, you can use the [Nais Console](../../operate/console/README.md) to view and manage vulnerabilities in your workloads.
