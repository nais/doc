# Vulnerability insights and management

Nais provides what you need to secure your software supply chain and manage vulnerabilities in your workloads.

The [SBOM and vulnerability detection overview](explanations/sbom-and-vulnerabilities.md) explains how image builds, scanning, Nais API, Console and the CLI fit together.

Get started by using our [GitHub Actions](how-to/sbom.md) to generate SBOMs and attestations for your workloads.

Inspect findings in [Nais Console](../../operate/console/README.md) or the [Nais CLI :octicons-link-external-16:](https://cli.nais.io). Record assessments and suppressions in Console.
